# Assets And Config

Covers: `Content`, `Config`, map and Blueprint integration points

## Entry Points

- `Config/Default*.ini`: project, engine, game, input, and gameplay tag settings
- `Content/Maps`: test and runtime maps
- `Content/Episode`: episode Blueprint, character, material, mesh, texture assets
- `Content/Bluepirnts`: project Blueprint assets; preserve the current path spelling
- `Content/Data`: data assets and test data
- `Content/Models/Delivery`: delivery robot meshes

## Notes

- Blueprint classes and data assets bind C++ properties into maps and test workflows
