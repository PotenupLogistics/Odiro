## 운행 차등 기준 (시행규칙·고시 + 보도자료 종합)

**같은 15km/h 상한이지만 무게별 실효 속도 제한**:

| 로봇 + 적재물 합산 무게 | 최고 허용 속도 |
|---|---|
| ≤ 100 kg | **15 km/h** |
| 100 kg < ~ ≤ 230 kg | **10 km/h** |
| > 230 kg (~ 500 kg 상한) | **5 km/h** |

→ **정책문서 §5 `max_speed` 파라미터에 중요한 영향**:
- 보수형 5 km/h는 무게 230kg 초과 로봇의 법정 상한과 일치
- 균형형 10 km/h는 무게 100~230kg 로봇의 법정 상한과 일치
- 효율형 12 km/h는 무게 100kg 이하 로봇만 허용 (12 < 15)

## 정책문서 §5 보정 권고 (Critical)

**현재 §5는 `max_speed`만 단일 파라미터로 다룸 → 무게 차등을 반영해야 함**.

권고 추가:

```python
def get_legal_max_speed(robot_mass_kg, payload_kg):
    total = robot_mass_kg + payload_kg
    if total <= 100: return 15  # km/h
    elif total <= 230: return 10
    elif total <= 500: return 5
    else: return 0  # 인증 불가
```

→ DOE 실험에서 **무게×속도 조합**을 추가 IV(Independent Variable)로 다룰 것을 고려.

## 법적 의무

- 실외이동로봇은 **보행자와 동일한 기준**으로 신호 준수
- **신호 위반·무단횡단 시 운용자(operator)에 범칙금**
- 사고 시 손해 책임 → 책임보험 의무 (지능형로봇법 제40조의4)

## 손해보장 (책임보험) 체계

- **한국로봇산업협회** ↔ KB손해보험·삼성화재·DB손해보험과 협약 (2023.11)
- 보험 가입은 인증·운영의 전제

→ 정책문서 §4 fallback 시 손해 보고 절차를 책임보험 약관과 연계 가능.
