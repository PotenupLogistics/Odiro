# 어리버리 시연 영상 자막 초안

기준 시간: 5분

## 전체 흐름

| 구간 | 탭 / 장면 | 핵심 메시지 |
| --- | --- | --- |
| 00:00-00:25 | 시작 탭 | 프리셋으로 실험 환경을 빠르게 시작 |
| 00:25-01:45 | 시나리오 편집 탭 | 직접 편집과 AI 생성으로 시나리오 구성 |
| 01:45-02:35 | 로봇 구성 탭 | 주행 성향과 센서 조건 조정 |
| 02:35-03:00 | 실험 탭 | 반복 실험 조건 설정 |
| 03:00-03:25 | 시뮬레이션 실행 | 5배속으로 여러 에피소드 실행 |
| 03:25-05:00 | 실험 결과 탭 | 리플레이, 통계, AI 분석으로 결과 확인 |

## 00:00-00:25 시작 탭

```text
안녕하세요, 어리버리 팀의 시뮬레이션 플랫폼, 어디로심 입니다.

처음 프로그램을 실행하면 프로젝트를 열거나 새로 만들 수 있습니다.

새 프로젝트를 시작합니다.

시나리오, 로봇 프로필, 행동 정책 프리셋을 선택하여
기본 실험 환경을 빠르게 구성합니다.

프로젝트를 실행하면 실험 과정에 따라 작업을 진행할 수 있습니다.
```

## 00:25-01:45 시나리오 편집 탭

```text
먼저 시나리오 편집으로 넘어갑니다.

기본 프리셋에는 짧은 길이의 보행로가 있고 우측에는 로봇이 피해야 할 차로가 있습니다.

먼저 포인트와 라인을 잡아 주행 구간의 형태를 바꿉니다.

로봇의 출발지와 목적지를 조정합니다.

장애물 에셋을 선택하여 지면에 직접 배치합니다.

배치한 장애물은 이동과 회전을 세밀하게 조정할 수 있습니다.

고정값과 범위값을 설정해 실험 조건을 다양하게 만들 수 있습니다.

시나리오 생성 기능을 테스트해보겠습니다.

원하는 주행 상황을 입력하고 생성 버튼을 누릅니다.

AI가 요청 의도를 분석해 시나리오 초안을 생성합니다.

생성된 시나리오는 편집 화면에서 바로 확인하고 마찬가지로 수정할 수 있습니다.

완성된 시나리오를 저장합니다.
```

## 01:45-02:35 로봇 구성 탭

```text
다음으로 로봇 구성 탭으로 넘어갑니다.

시뮬레이션할 로봇의 주행 및 센서 관련 값들을 조절할 수 있습니다.

수치값은 슬라이더로 직관적으로 조절합니다.

센서 시각화를 켜면 거리와 범위를 확인할 수 있습니다.

LiDAR 센서의 입체각 및 감지 방식을 설정합니다.

감속 거리와 정지 거리를 조절해 로봇의 주행 성향을 맞춥니다.
```

## 02:35-03:00 실험 탭

```text
이제 실험 탭에서 실행 조건을 설정합니다.

반복 횟수를 높이고 배속을 조절합니다.

제한 시간 및 전복 각도 같은 지표도 설정할 수 있습니다.

설정이 끝나면 시뮬레이션을 시작합니다.
```

## 03:00-03:25 시뮬레이션 실행

```text
하나의 시나리오는 매 실행마다 범위로 되어 있는 값들이 샘플링되어
서로 다른 에피소드로 저장됩니다.

성공, 충돌, 전복, 시간 초과 같은 이벤트와
센서가 인지한 대상, 로봇이 취한 행동이 실험 기록으로 저장됩니다.
```

## 03:25-05:00 실험 결과 탭

```text
실험이 끝나면 결과 분석 탭에서 전체 결과를 확인합니다.

에피소드별 성공 여부와 주요 통계를 한눈에 볼 수 있습니다.

리플레이를 통해 각 에피소드의 진행 상황을 파악합니다.

시야각을 조절해 문제 상황을 다양한 관점에서 봅니다.

배경, 포인트 클라우드, 센서 시각화를 켜고 끌 수 있습니다.

센서 데이터와 주행 장면을 함께 보며 로봇이 인지한 상황을 파악합니다.

재생 바의 이벤트를 클릭하면 발생 시점으로 바로 이동합니다.

실행한 실험에 대해 AI 결과 분석을 실행합니다.

문제 패턴을 정리하고 반복 실패 원인과 개선 방향을 추천합니다.

연구자는 로그를 직접 뒤지지 않고
다음 실험 방향을 빠르게 잡을 수 있습니다.
```

## 마무리 자막

```text
어디로심은 시나리오 생성부터 실험 실행, 리플레이, AI 분석까지 연결합니다.

반복 작업은 줄이고, 사용자가 로봇 정책 개선에 더 집중할 수 있게 합니다.

시청해주셔서 감사합니다.
```
