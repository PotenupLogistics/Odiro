# 시뮬레이션 인터페이스

제품 개념, 데이터 흐름을 정의.

## 핵심 용어

### 데이터 단위

| 용어                             | 형식   | 정의                               | 구성                                      |
| -------------------------------- | ------ | ---------------------------------- | ----------------------------------------- |
| `Scenario`<br>(`ScenarioSample`) | JSON   | 로봇이 수행할 작업과 환경 구성     | 시작/도착 위치, 도로 구성, 장애물 배치    |
| `ScenarioTemplate`               | JSON   | 랜덤 `Scenario` 생성을 위한 패턴   | 다양한 시작/도착 위치, 랜덤한 장애물 배치 |
| `Profile`                        | JSON   | 로봇의 물리적 특성                 | 최대 속도, 토크, 무게, 센서 범위          |
| `Setting`                        | JSON   | 시뮬레이션 설정                    | 에피소드 구성, 반복 횟수                  |
| `Policy`                         | Python | 행동을 결정하는 알고리즘 또는 모델 | decision tree, custom policy              |

### 실행 단위

| 용어                | 정의                                                           |
| ------------------- | -------------------------------------------------------------- |
| `Experiment`        | `Scenario`, `Profile`, `Setting`, `Policy`로 구성된 실험 단위  |
| `Run`(`Simulation`) | 한 `Experiment` 내에서 `Policy`만 변경하여 실행되는 단위       |
| `Episode`           | `Run` 내에서 `Scenario` 하나가 시작부터 종료까지 실행되는 단위 |

### 로봇 구성

| 용어      | 정의                                               | 모방 대상               |
| --------- | -------------------------------------------------- | ----------------------- |
| 로봇      | 로봇의 물리적 특성과 동작을 모방한 액터            | 실제 로봇의 물리적 특성 |
| 지도 정보 | 로봇 주행 환경의 지리적 레이아웃                   | GPS 지도                |
| 인식 정보 | 로봇의 주변 환경 인식 데이터                       | 카메라, LIDAR, IMU 센서 |
| 행동      | 로봇이 수행하는 제어 동작                          | 실제 로봇 제어 방식     |
| 행동 정책 | 주어진 상황에서 행동을 결정하는 알고리즘 또는 모델 | 실제 제어 알고리즘      |

### 시뮬레이션 기록

| 용어      | 형식  | 정의                                   | 구성 요소                                 |
| --------- | ----- | -------------------------------------- | ----------------------------------------- |
| `actions` | JSONL | 로봇의 입력·출력 데이터                | 기록 시간, 입력 데이터, 출력 행동         |
| `events`  | JSONL | 발생한 사건 또는 변화                  | 발생 시간, 이벤트 유형, 관련 객체         |
| `trace`   | JSONL | 로봇과 무관한 환경 정보                | 기록 시간, 환경 변경, 로봇이 못 본 데이터 |
| `result`  | JSON  | 한 `Episode`의 결과                    | 총 실행 시간, 성공/실패, 충돌 횟수 등     |
| `summary` | JSON  | 한 `Run` 내의 모든 `Episode` 결과 요약 | 총 실행 시간, 성공률, 주요 실패 원인 등   |

### 평가

| 용어          | 정의                            | 예시                              |
| ------------- | ------------------------------- | --------------------------------- |
| 실패 상황     | 시나리오 실패 조건              | 보행자 충돌, 도로 이탈, 시간 초과 |
| 행동 평가     | 한 순간의 행동 적절성 평가      | 이상 행동 탐지                    |
| 정책 평가     | 행동 정책의 안정성 평가         | 취약 시나리오 탐지, 개선점 제안   |
| 시나리오 평가 | 시나리오의 난이도와 적합성 평가 | 정책 평가용 시나리오 식별         |

## 실행 흐름

1. ScenarioTemplate 작성
   - ScenarioEditor 또는 ScenarioAgent가 ScenarioTemplate 생성/수정
2. Profile 작성
   - ProfileEditForm 에서 Profile 생성/수정
3. Experiment 구성
   1. Setting 작성
   2. Profile 선택
   3. ScenarioTemplate 선택 후 원하는 양의 Scenario 생성
   4. Policy 작성
4. Simulation 실행
   1. Simulator 프로세스가 각 Scenario마다 Episode 생성
      1. 로봇은 입력 데이터를 `PolicyRuntime`에 전달, 행동 판단 수신
      2. 입출력, 이벤트, 환경 데이터 `Run` 로그에 기록
   2. 각 Episode 종료 시 결과 기록
   3. Run 종료 시 summary 기록
5. 시뮬레이션 결과 AI 분석
   1. Run summary를 분석하여 Run 간 차이 분석
   2. Episode result 분석하여 Episode 간 차이 분석
   3. 분석 결과를 바탕으로 Policy 개선 · ScenarioTemplate 개선 방향 도출
